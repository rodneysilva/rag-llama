Ref: ChatGPT attachments · Gmail chips

As coleções selecionadas são pills grudadas no composer (como anexos de e-mail): o RAG está literalmente no seu input — impossível esquecer o que está ativo. Modo e MCP ficam na linha de cima.

↑ pills = o que entra na busca · chip de modo = como a LLM usa

▸ quando usar este layout
  • Melhor para: o caso padrão do projeto — poucas coleções ativas (1–4), troca frequente.
  • Pills com max-width + truncate: nome longo nunca quebra (coleções da LLM são imprevisíveis).
  • É o layout mais próximo do ColecaoPicker atual do ChatTab — evolução natural.
