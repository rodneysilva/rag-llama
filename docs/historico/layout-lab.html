Chat com composer resiliente

Padrão de mercado: ChatGPT · Claude · Gemini — aplicado ao chat do RagAroy

▸ Ver as técnicas deste exemplo 
1. Toolbar quebra, não vaza
.c-row1 { display:flex; flex-wrap:wrap; gap:.45rem }

2. Nome dinâmico trunca (nunca estica o pill)
.pill2    { max-width:11rem; display:inline-flex }
.pill2 .t { overflow:hidden; text-overflow:ellipsis }
.pill2 .x { flex-shrink:0 }        /* o ✕ nunca é comprimido */

3. Container query: rótulo some, ícone fica
@container (max-width: 480px) {
  .btn .lbl { display:none }   /* "Anexar" some, 📎 fica */
}

Por que @container e não @media?
O chat pode estar numa coluna de 380px dentro de uma janela
de 1920px — @media (largura da JANELA) mentiria;
@container responde à largura REAL do componente.

Toolbar de filtros com chips

Padrão de mercado: Gmail · Linear · Jira — filtros de coleções do RagAroy

scroll-snaptruncate no chip tabular-nums

Chips com contadores dinâmicos e rótulos que vêm do servidor (categorias da LLM). Quando não cabem: a trilha rola horizontalmente com snap (padrão Gmail mobile) em vez de quebrar o layout. A busca assume flex:1 — ocupa o que sobrar.

a trilha de chips rola (snap) · a busca encolhe até sumir do foco

Variação — categorias geradas pela LLM na ingestão (rótulos imprevisíveis e longos):

▸ Ver as técnicas deste exemplo 
1. Trilha de chips: scroll com snap (não quebra, não vaza)
.chips { display:flex; overflow-x:auto; scrollbar-width:none;
         scroll-snap-type:x proximity }
.chip  { scroll-snap-align:start; white-space:nowrap }

2. Rótulo do chip pode vir da LLM (imprevisível):
.chip .t { max-width:9rem; overflow:hidden; text-overflow:ellipsis }

3. Busca flexível: .filters .input { flex:1; max-width:14rem; min-width:0 }

4. Contadores não dançam: .chip .n { font-variant-numeric:tabular-nums }
(sem isso, "9→10" muda a largura e o layout "pula")

▸ Ver as técnicas deste exemplo 
1. Grid que se reorganiza SOZINHO (sem media query):
.stats { display:grid;
  grid-template-columns: repeat(auto-fit, minmax(13rem, 1fr)) }
  auto-fit → cria quantas colunas COUBEREM

.stat .k { overflow:hidden; text-overflow:ellipsis }

▸ Ver as técnicas deste exemplo 
1. A tabela tem uma largura MÍNIMA honesta — nunca esmaga:
table { min-width:36rem }        /* menos que isso: SCROLL */
.tblwrap { overflow-x:auto }

2. Nome de coleção (dado dinâmico do Qdrant):
td .name .t { overflow:hidden; text-overflow:ellipsis; white-space:nowrap }

3. A mágica: linha vira CARD no palco estreito
@container (max-width: 640px) {
  table, thead, tbody, tr, td { display:block }
  thead { display:none }               /* sem cabeçalho */
  tr    { border:1px solid; border-radius:.6rem; margin-bottom:.6rem }
  td    { display:flex; justify-content:space-between; gap:1rem }
  td::before { content:attr(data-l) }  /* o label reaparece! */
}

4. Descrição longa no card: máx 2 linhas
.desc { display:-webkit-box; -webkit-line-clamp:2;
        -webkit-box-orient:vertical; overflow:hidden }

▸ Ver as técnicas deste exemplo 
1. Grid que preenche (auto-FILL):
.gal { grid-template-columns: repeat(auto-fill, minmax(9.5rem, 1fr)) }

2. Thumb sempre quadrada, imagem nunca deforma:
.thumb { aspect-ratio: 1/1; overflow:hidden }
(a mídia usa object-fit:cover dentro — corta, não estica)

compensando o degradê escuro por baixo do texto.

Command palette (⌘K / Ctrl+K)

Padrão de mercado: Raycast · Linear · Cursor · Vercel — ⌘K do RagAroy

Ctrl+K real↑↓ navega ⏎ executamax-height scroll

O padrão de navegação por comando que virou referência de mercado. Está funcional aqui: pressione Ctrl+K (ou o botão) — filtre, navegue com ↑ ↓, execute com ⏎. Rótulos truncam e cada item mostra um hint de teclado.

ou pressione Ctrl+K agora
▸ Ver as técnicas deste exemplo 
1. Overlay centrado com largura CAPADA (nunca estica):
.cmdk { width:min(34rem, 100%) }    /* min(): a menor das duas */

2. Lista com altura máxima — o resto faz scroll:
.cmdk .list { max-height:20rem; overflow-y:auto }

3. Item: rótulo trunca, hint fica:
.it    { display:flex; gap:.7rem; min-width:0 }
.it .t { flex:1; overflow:hidden; text-overflow:ellipsis }
.it .h { flex-shrink:0 }         /* o kbd nunca é comprimido */

4. Acessível de verdade: ↑/↓ move, ⏎ executa, Esc fecha,
foco automático no input — é o contrato do usuário de ⌘K.

5. No RagAroy real: CommandK.tsx usa CustomEvent global
("ragaroy:cmdk") — qualquer tecla/botão abre a mesma paleta.

▸ Ver as técnicas deste exemplo 
1. Input com prefixo (padrão .env) — o clássico que quebra:
.fwrap  { display:flex; min-width:0 }      /* cadeia autoriza encolher */
.fwrap .fix { flex-shrink:0; white-space:nowrap } /* sufixo intacto */
