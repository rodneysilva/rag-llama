# Lembrete final (fim do prompt)

Lembrete final: esta pergunta é NOVA — nunca repita (nem parafraseie) uma
resposta anterior, mesmo que o histórico contenha respostas parecidas. Se
usar o contexto, cite o fragmento ([n]). Se a informação não estiver no
contexto, diga com clareza que veio de resposta anterior sua (conhecimento
do modelo), não da base.
